Rclone Pessoal Linux

Esta página descreve uma integração OAuth destinada exclusivamente ao uso pessoal do proprietário da conta Google para acesso e sincronização seletiva de arquivos entre seu computador Linux e seu Google Drive, utilizando o software de código aberto Rclone.

Finalidade

O Rclone permite ler, copiar, alterar e, quando autorizado e configurado, excluir arquivos do Google Drive. A sincronização será limitada operacionalmente às pastas selecionadas pelo proprietário, embora a autorização OAuth possa oferecer permissão mais ampla sobre o Google Drive. A sincronização não substitui um backup independente.

Como funciona

A autorização é concedida pelo próprio proprietário na página de consentimento do Google. O software Rclone roda localmente no computador e se comunica com a API do Google Drive. Esta página é apenas informativa e não realiza login, upload, download ou armazenamento de documentos.
